# TS1201 红外遥控器使用指南

本指南适用于工程人员已经安装并验收的 TS1201 ZHA 试点系统。它目前需要配套集成，尚不是官方开箱即用的版本。

## 找到日常控制

进入 Home Assistant 的“设置 → 设备与服务 → ZHA”，打开红外设备，再从“已连接的设备”进入“TS1201 红外遥控器”。也可以在设备与服务中打开“TS1201 IR Remote / TS1201 红外遥控器”。建议把其中的空调和常用命名按钮加入自己的仪表板。

第一次没有匹配过空调、也没有保存按键时，页面不会凭空生成家电控制。先选下面适合自己的方式。

## 空调：按品牌匹配

先将红外盒正对空调，再在原 ZHA 红外设备页选择空调品牌。按“开始匹配”会直接发送第一套测试码；有响应才按“确认匹配成功”，没有响应则按“下一套码”。需要重发同一套时按“重试当前码”。设备提示“传输完成”只表示红外盒完成传输，仍需观察空调。

确认具备完整控制表的码库后，关联的“TS1201 红外遥控器”自动出现空调面板，可调电源、模式、温度和风速。可选范围以当前面板为准。关机时单独调整温度或风速只保存待机设置；选择制冷等运行模式会开机。

空调没有状态回传，面板显示的是上次命令估计。使用原装遥控器后，实际状态可能与面板不同。不要将面板当作室温传感器或真实运行反馈。

## 自学习：保存常用遥控器按键

1. 在关联遥控器页面填写“按键名称”，例如“电视关机”或“空调制冷26℃”。
2. 点击“开始按键学习”，看到学习提示后，将原装遥控器对准红外盒按一次目标按键。学习窗口为60秒。
3. 捕获完成后，确认来自刚才的遥控器，再点击“确认保存新按键”；待保存结果10分钟后失效。
4. 页面生成该名称的发送按钮。点击并观察家电响应，确认有效后再用于日常控制。

页面只在适用时提供保存、更新、选择、删除和撤销等管理操作。没有学到完整信号时，不会提供可保存的结果。名称可以先清空重新填写，但开始学习、保存和改名必须有有效名称。

最多保存32个按键，每个名称1–48个字符，不能重名。已有按键可以改名、替换编码、删除或撤销最近删除。改名和撤销保留原实体标识。学习一个空调温度键，只会得到这个固定状态的按钮，不能自动推导全部温度和风速。

## 遇到问题

| 页面表现 | 处理方式 |
| --- | --- |
| 找不到空调面板 | 回到原 ZHA 红外设备，确认已保存正确的候选；只有有完整控制表的码库才生成空调实体。 |
| 按键库为空 | 先命名并完成一次学习；旧的“最近学习码”不会自动导入。 |
| 学习超时或捕获失败 | 检查遥控器电池、距离和方向，重新开启一次学习；已有按键不受影响。 |
| 提示设备不可用 | 检查红外盒供电和 ZHA 连接，等待恢复后再操作。不要连续点击发送。 |
| 传输完成但家电无响应 | 检查红外方向、无遮挡和距离；品牌匹配可能不适用该型号，使用下一候选或原遥控器学习。 |
| 提示上次删除未完成 | 原按键被保留，可继续使用或重新删除；不要手工修改数据库。 |
| 待保存结果过期 | 重新学习，避免将旧信号误保存为新按键。 |

安装与维护由工程人员按 [安装说明](ts1201_zha_installation.md) 进行。升级前备份 Home Assistant；码库、学习键及实体信息分别由 ZHA/HA 管理，不能只备份 Python 文件来代替系统备份。
